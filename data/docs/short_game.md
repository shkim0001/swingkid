# 숏게임 (어프로치·벙커)

> 교육용 더미 데이터입니다. 공개 자료를 참고해 직접 쓴 입문자용 요약입니다.

## 어프로치
그린 주변 30m 이내 샷입니다. 스탠스를 좁게 서고 체중을 왼발에 60% 정도 둡니다.
손목을 많이 쓰지 말고 어깨 회전으로 백스윙 크기를 조절해 거리를 맞춥니다.

## 벙커샷
벙커에 빠졌을 때는 공을 직접 치지 않고 공 뒤 3~5cm 모래를 칩니다. 모래가 공을 밀어 올려 빠져나옵니다.
- 클럽 페이스를 조금 열고 샌드웨지를 씁니다.
- 발을 모래에 살짝 비벼 넣어 자세를 고정합니다.
- 규칙상 백스윙 전에 클럽을 모래에 대면 안 됩니다.
- 공 뒤 모래를 친 뒤에도 스윙을 끝까지 이어 피니시를 합니다.
