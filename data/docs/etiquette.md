# 에티켓

> 교육용 더미 데이터입니다. 공개 자료를 참고해 직접 쓴 입문자용 요약입니다.

## 라운드 전 준비
티오프 30분 전에 도착합니다. 가벼운 몸풀기(스트레칭)로 어깨·허리·손목을 천천히 풀고 연습 그린에서 퍼팅 감을 익힙니다.

## 다른 사람이 칠 때
다른 사람이 칠 때는 조용히 하고 움직이지 않습니다. 치는 사람의 정면이나 바로 뒤에 서지 않습니다.

## 그린 위에서
다른 사람이 퍼팅할 때는 퍼팅 라인(공에서 홀까지 굴러갈 길)을 밟지 않고, 퍼팅하는 사람의 시야에 들어가지 않는 옆쪽에 섭니다.
공이 떨어진 자국(피치 마크)은 직접 수리합니다.

## 진행 속도
앞 조와 간격이 벌어지지 않게 합니다. 공을 찾는 시간은 3분을 넘기지 않습니다.
